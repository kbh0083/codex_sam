## 5. JSON parse retry 기준

- qwen3.5 harness에는 별도 JSON parse retry가 없다.
- qwen3.6 harness는 `PARSE_RETRIES=3`을 둔다.
- JSON parse retry는 모델 응답이 유효한 JSON 객체로 파싱되지 않을 때 같은 조건으로 다시 호출하는 실행 안정화 정책이다.
- retry 대상은 top-level 배열, 설명문 혼입, reasoning-only 응답, empty content 같은 형식 실패다.
- 이 retry는 누락 주문, 펀드명, 금액, 날짜를 수정하는 deterministic 후처리가 아니다. 업무적 추출 오류는 그대로 `FAIL`로 판정한다.
